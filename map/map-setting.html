Network map symbols and display configuration

📍 Map Symbols / Location Types

Customer, Pole, Switch এবং Custom Type-এর Icon ও Color পরিবর্তন করুন। এখানে পরিবর্তন করলে Map-এ সেই Symbol দেখা যাবে।

Symbol হিসেবে Emoji ব্যবহার করতে পারেন। যেমন Customer = 👤, Pole = 🗼, Switch = 🔀, Distribution Box = 📦। Icon ও Color Save করার পর Map-এ আপডেট হবে।

🗺️ Map Display

Map-এর প্রাথমিক অবস্থান ও Marker-এর আকার ঠিক করুন।

👁️ Connection Visibility

প্রতিটি Connection আলাদাভাবে Show বা Hide করুন।

🎨 Connection Design

Wire, Fiber ও Drop-এর Color, Width এবং Style পরিবর্তন করুন।

🔒 Polygon Area Lock

ম্যাপে নির্দিষ্ট এলাকা তৈরি করুন। Area Lock চালু থাকলে Polygon-এর বাইরের Location Map-এ দেখানো হবে না।

Map-এ ক্লিক করে কমপক্ষে ৪টি পয়েন্ট তৈরি করুন। পয়েন্টগুলো Drag করে সরাতে পারবেন। Finish Polygon করার পর Save Settings চাপুন।
